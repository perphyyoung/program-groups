# e2e 测试范围

每个文件对应一类场景。两位数字前缀只表示阅读顺序，与执行顺序无关——Playwright 并行跑。

| 文件                       | 覆盖范围                                     |
| -------------------------- | -------------------------------------------- |
| `01-app-shell.spec.ts`     | 启动骨架、侧栏计数、刷新按钮、页脚           |
| `02-scan.spec.ts`          | 扫描结果、首字母占位、已忽略、重复项         |
| `03-groups.spec.ts`        | 新建分组、自动聚焦、多组归属、重启持久化     |
| `04-manual-ignore.spec.ts` | 手动忽略、重启保留、拖入分组恢复             |
| `05-notes.spec.ts`         | 应用行与已忽略行备注、备注搜索、重启保留     |
| `06-context-menu.spec.ts`  | 行右键菜单、路径置灰、键盘打开、输入框排除   |
| `07-settings.spec.ts`      | 设置页图标缓存增量更新与全量重建             |
| `08-green-soft.spec.ts`    | 绿色软件目录、全部 exe、手动忽略、green 图标 |
| `09-source-filter.spec.ts` | 未分组栏按来源筛选、计数与重置               |

## 01-app-shell.spec.ts

验证启动后的窗口骨架，不涉及分组操作：

- 启动即自动扫描，默认停在「未分组栏」
- 标题、搜索框、刷新按钮（固定文案「刷新」且可用）
- 侧栏「全部应用栏 / 未分组栏 / 已忽略栏」计数均为 1
- 未分组栏不显示「包含已忽略项」复选框
- 页脚「共 1 个应用 · 未分组 1」

新增主界面常驻控件时，在这里补断言。

## 02-scan.spec.ts

验证扫描结果与「已忽略栏」：

- 应用卡片出现；扫描不提取图标，显示首字母「测」占位
- 扫描完成提示只含新增 / 缺失 / 忽略 / 重复，不提示图标状态
- 「已忽略栏」计数为 1
- 默认折叠的「帮助/说明」「重复快捷方式」两组，计数均为 1
- 展开「帮助/说明」后显示 `测试应用 帮助` 与「启动」按钮
- 展开「重复快捷方式」后显示 `测试应用 副本`、「已收录为「测试应用」」与删除建议说明
- 搜索「副本」时只剩重复组且自动展开；清空搜索后保留手动展开状态
- 追加 14 个帮助快捷方式并刷新后，滚动列表到底部，帮助组头仍吸顶在滚动区顶部
- 切到「全部应用栏」：默认未勾选；勾选「包含已忽略项」后出现已忽略项与「已忽略项」标题，重复项不出现；搜索「帮助」仍命中；取消勾选后区块消失
- 切回「未分组栏」后复选框隐藏，应用卡片仍在

## 03-groups.spec.ts

验证分组主链路：

- 打开新建弹窗后输入框自动聚焦
- 新建「测试组」后仍停在「未分组」，应用卡片可见
- 选中应用加入「测试组」；再建「常用」并二次归属
- 应用卡片同时显示「测试组」「常用」标签
- 重启后两个分组计数与归属保留
- 分组「⋯」菜单可重命名与删除；重命名空名 / 未修改不可保存，重名错误留在弹窗
- 删除弹窗显示组内应用数，取消默认聚焦；Esc 后焦点回到「⋯」，删除后应用保留
- 分组排序方式切换：手动 / 名称 / 创建顺序；切回手动恢复原顺序
- ↑/↓ 箭头切换正序 / 倒序，三种方式共用；手动倒序按可见顺序拖拽，重启后方式、方向与手动顺序保留
- 手动排序下拖拽握把出现插入线，Alt+↑/↓ 可改序

## 04-manual-ignore.spec.ts

验证手动忽略：

- 每行有「手动忽略」入口
- 点击后应用从「未分组」消失，侧栏「已忽略」计数包含手动忽略
- 全部应用勾选「包含已忽略项」时，手动忽略应用也出现在已忽略项区块，可取消忽略
- 已忽略栏出现「手动忽略」组，行内可「取消忽略」
- 重启后手动忽略仍保留
- 拖拽入口是行首握把（`getByTitle("拖动「测试应用」到分组")`），整行不可拖
- 拖到侧栏分组后自动解除手动忽略，应用出现在该分组

## 05-notes.spec.ts

验证行内备注：

- 应用行 hover 后中间列显示「＋ 备注」，添加后显示备注文本
- 备注输入聚焦不带动外层页面滚动
- 搜索备注「截图」仍能看到应用
- 已忽略规则行同样支持备注
- 搜索备注「帮助文档」只保留命中的帮助分组，重复组消失
- 重启后备注仍保留

## 06-context-menu.spec.ts

验证行右键菜单：

- 应用行右键出现「启动 / 打开目标路径 / 打开链接路径」三项，Esc 关闭且焦点回到行
- Tab 关闭菜单，焦点继续向后移动
- Shift+F10 可打开同一菜单
- 已忽略行同样三项；目标文件不存在时「打开目标路径」置灰
- 全部应用栏的规则忽略行也显示「启动」
- 备注输入框内右键不弹出行菜单

## 07-settings.spec.ts

验证设置页的图标缓存：

- 侧栏「设置」进入独立页，隐藏搜索与刷新
- 图标来源默认只勾 `start`；`store`、`green` 未勾
- 初始进度条 `value = 0`、`max = 1`
- 「更新图标缓存」后进度条变为 1 / 1，列表行出现 `pg-icon://` 图标
- 勾选「全量重建」后按钮变「重建图标缓存」，点击可再次提取

## 08-green-soft.spec.ts

验证绿色软件目录：

- 用例自建临时 green 目录（复制 `notepad.exe`），不使用本机真实目录
- 目录内 3 层以内的 `.exe` 都成为应用，行名旁显示 `green` 徽标；名称 hover 显示完整路径
- 辅助 exe 可通过「手动忽略」收起
- 设置页显示目录与 `N / 5`；勾选 `green` 后「更新图标缓存」生成 `pg-icon://` 图标
- 移除目录先确认（原生 dialog，默认聚焦取消，Esc 关闭）；取消保留，确认后该目录下应用从列表消失

## 09-source-filter.spec.ts

验证未分组栏来源筛选：

- 临时 start 目录与 green 目录各 1 个应用，筛选行显示「全部 2 / start 1 / green 1」
- 点击单来源后只显示对应应用；搜索在筛选内生效
- 切换其他栏再回到未分组，筛选重置为「全部」

## 约定

- 用例一律 `import { test, expect } from "./fixtures"`：实例按 spec 文件复用，换文件时自动关旧实例并删数据目录
- 启动耗时不计入用例 timeout（slot fixture 自带 15s 预算）
- 需要「关闭再打开」时用 `slot.relaunch()`，不要自己 launch；重启后通过 `slot.page` 取新页面
- 数据建在 `slot.base` 下，随实例销毁自动清理，用例结束不需要手动 rm
- 固定扫描 fixture 在 `fixtures.ts` 里创建：`测试应用`、`测试应用 帮助`、`测试应用 副本`，均指向 `notepad.exe`
- 用例内追加快捷方式用 `createShortcut(slot.scanDir, ...)`，再点「刷新」即可，不需要重启
- 用例标题与结果由 fixtures 自动写入 `pg.log`（`▶` / `✓ 通过` / `✗`）
- 共用函数在 `e2e-helper.ts`（`e2eEnv` / `makeWorkdir` / `createShortcut` / `launchApp`），日志在 `e2e-logger.ts`
- e2e 固定注入 `PG_STORE_JSON=[]`，不扫描本机真实 Store，避免环境差异；注入格式含 `Name` / `AppID` / `SignatureKind`，Store 签名进应用，其他进已忽略
- 绿色软件目录用 `PG_GREEN_DIRS`（分号分隔）在启动时写入 `meta.green_dirs`，运行期统一读数据库，不读取本机真实路径
- 用例覆盖范围变化后，同步更新本文件对应章节
